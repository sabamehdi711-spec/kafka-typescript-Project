
# Kafka-Based Event Streaming Project

A TypeScript-based event-driven application that demonstrates real-time message streaming using Apache Kafka and KafkaJS.

## 🚀 Technologies Used

- TypeScript
- Node.js
- Apache Kafka
- KafkaJS
- Docker
- Git & GitHub

## 📌 Project Overview

This project demonstrates how Apache Kafka can be used for asynchronous and real-time communication between application components.

The application uses Kafka to publish messages to a Kafka topic and consume those messages for processing.

The project is implemented using TypeScript and Node.js, with Docker used to simplify the Kafka development environment.

🔧 Installation
Clone the repository:
git clone https://github.com/sabamehdi711-spec/kafka-typescript-Project.git
Navigate to the project:
cd kafka-typescript-Project
Install the dependencies:
npm install
🐳 Start Kafka
Start the Kafka environment using Docker:
docker compose up -d
Check the running Docker containers:
docker ps
▶️ Run the Project
Run the TypeScript application using the command configured in package.json.
For example:
npm run dev
The application connects to Kafka and demonstrates message publishing and consumption.
